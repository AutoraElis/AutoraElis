# Portfólio Literário - Lise Elis 📖✨

Este é um projeto de site pessoal e portfólio literário desenvolvido com foco em apresentar obras de ficção romântica e fantasia. O design possui uma estética orgânica, utilizando recortes curvos, animações fluidas e uma paleta de cores vibrante e romântica (tons de Gelo, Magenta, Rosa e Verde-Oliva).

##  Funcionalidades

O site é composto por uma única página (Single Page) dividida nas seguintes seções:
- **Hero/Header:** Apresentação com letreiro rotativo (Marquee) animado com CSS.
- **Sobre a Autora:** Espaço dedicado à biografia, com design de imagem orgânica utilizando `border-radius` dinâmico.
- **Últimos Lançamentos:** Grade de cards (CSS Grid) apresentando os três livros mais recentes.
- **Galeria de Personagens:** Um carrossel interativo construído em JavaScript puro para navegar entre os perfis dos personagens (ex: Clary, Jace, Magnus).
- **Textos & Inspirações:** Uma seção estilo blog para crônicas, dicas de escrita e atualizações.

##  Tecnologias Utilizadas

O projeto foi construído puramente com as tecnologias base da web, sem a necessidade de frameworks externos, ideal para customização e estudos de estruturação:
- **HTML5:** Estruturação semântica.
- **CSS3:** Estilização com variáveis (`:root`), Flexbox, CSS Grid e animações (`@keyframes`).
- **JavaScript (Vanilla):** Lógica do carrossel interativo de personagens.

##  Tipografia
- **Cinzel:** Títulos elegantes e sofisticados.
- **Great Vibes:** Detalhes e subtítulos cursivos, trazendo o tom romântico.
- **Lora:** Corpo do texto de fácil leitura e com pegada literária.
